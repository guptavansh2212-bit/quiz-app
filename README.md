# 🐍 Terminal-Based Python Quiz Application

A lightweight, interactive command-line quiz application built in Python. 
This application allows users to register with their name, 
select their preferred programming language to explore, 
and tests their knowledge with a structured point-scoring system.

## 🚀 Features
* *Participant Registration:* Captures the user's name for a personalized quiz experience.
* *Language Selection:* Gives users the freedom to choose which programming language topic they want to be tested on.
* *Interactive Scoring Matrix:* Evaluates user responses in real-time and awards *2 points* for every correct answer.

## 💻 Tech Stack
* *Language:* Python
* *Environment:* Command-Line Interface (CLI) / Terminal
